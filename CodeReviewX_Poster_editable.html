Objectives

Problem

  • Manual review: slow, subjective
  • Raw metrics: numbers, no reasons
  • Black-box ML: scores nobody can verify

Goals

  • Measure every function, deterministically
  • Rank bug-prone code from real history
  • Explain scores; refactor and re-score
Motivation. Thousands of functions, minutes to review. Show reviewers where to look first, and why.

AST parser logic

  • Python ast: cyclomatic, cognitive, nesting, length
  • Call graph per function
  • 13 quality factors, scored 0 to 100
  • Scope-aware undefined names; duplicate fingerprints
  • Critical finding caps health at 49

ML risk engine

  • 147,097 functions, 11 repos, bug-fix labels
  • 25 features, standardised logistic regression
  • Contribution = coefficient × value: every risk is explained exactly
  • High ≥ 7.1% · Medium ≥ 3.7%

LLM refactoring pipeline

  • 3 AST transforms: name constants, guard clauses, extract method
  • Unsafe changes skipped; result re-parsed
  • Whole file re-analysed: before vs after
  • Optional Claude call only rewords, never invents numbers
  • Runs with no API key
